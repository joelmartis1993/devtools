About URL encoding

URL encoding (also called percent-encoding) is how the web safely represents characters in a URL that would otherwise have a special meaning — like ?, &, #, spaces, or non-ASCII characters. Each problematic byte is replaced by a % followed by its two-digit hex value.

Component vs full URI

The Component mode (equivalent to JavaScript's encodeURIComponent) encodes everything that isn't a safe character — including /, ?, and &. Use it for individual query values, path segments, or form field values.

The Full URI mode (encodeURI) preserves the structural characters of a URL, encoding only spaces and other unsafe bytes. Use it when you have a complete URL and just want to clean it up.

When developers reach for it

  • Building share links: ?text=Check%20this%20out
  • Constructing OAuth redirect URIs and signed callback URLs
  • Embedding user-supplied search queries into API requests
  • Decoding access logs to read what visitors actually requested

Practical example

Encoding the value name=Ada Lovelace&role=admin in component mode produces name%3DAda%20Lovelace%26role%3Dadmin, which can be safely used as a single query parameter without breaking the URL structure.

For binary or token data, see the Base64 encoder.

Frequently asked questions

When should I use encodeURIComponent vs encodeURI?

Use encodeURIComponent for individual values inside a URL (query params, path segments). Use encodeURI when encoding a complete URL that already contains structural characters like :, /, and ?.

Why are spaces sometimes encoded as + and sometimes as %20?

+ is a legacy convention from application/x-www-form-urlencoded form bodies. Modern URL encoding uses %20. Both decode to a space.

Is URL encoding the same as Base64?

No. URL encoding escapes individual unsafe characters; Base64 re-encodes arbitrary bytes into a 64-character ASCII alphabet. Use Base64 for binary data, URL encoding for text in URLs.

Can I decode a URL safely?

Yes — decoding never executes anything. The tool runs entirely in your browser; nothing is sent over the network.
