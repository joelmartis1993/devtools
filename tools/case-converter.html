About text case conversion

Programming languages and ecosystems each have their own preferred naming convention, and converting between them is a tedious daily chore. JavaScript favors camelCase, Python uses snake_case, CSS classes are typically kebab-case, environment variables are CONSTANT_CASE, and React components are PascalCase. This tool converts your input into all of them simultaneously so you can copy the one you need.

Supported conventions

  • camelCase — JavaScript variables, JSON keys, Java methods
  • PascalCase — class names, React components, type names
  • snake_case — Python, Ruby, SQL columns
  • kebab-case — CSS classes, URL slugs, CLI flags
  • CONSTANT_CASE — environment variables, constants
  • Title Case — headings and user-visible labels
  • Sentence case — natural prose
  • UPPER / lower — when you just need to flatten

How the splitter works

The converter splits your input into words by detecting boundaries: existing dashes, underscores, spaces, and the transition between a lowercase letter and an uppercase letter. That means it understands all of "hello world", "helloWorld", "hello-world", and "hello_world" as the same two-word phrase, and converts them consistently.

Practical examples

Pasting userProfileSettings gives you user_profile_settings for your Python backend, user-profile-settings for the matching CSS class, and USER_PROFILE_SETTINGS for the environment variable that controls the feature flag — all without typing any of them by hand.

Frequently asked questions

How does the splitter detect words?

It looks for transitions between lower- and upper-case letters, plus dashes, underscores, dots, slashes, and whitespace. So helloWorld, hello_world, and hello-world all become the same two-word phrase.

Which case should I use for JavaScript variables?

camelCase for variables and functions; PascalCase for classes and React components; CONSTANT_CASE for true constants.

Are acronyms handled correctly?

Acronyms in input like parseHTML split as parse + html. The output is then re-cased per convention.
