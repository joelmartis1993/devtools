About Unix timestamps

A Unix timestamp (also called epoch time) is the number of seconds that have elapsed since 00:00:00 UTC on 1 January 1970, ignoring leap seconds. It's the canonical way computers store and exchange points in time — used in databases, log files, JWTs, HTTP cookies, and virtually every API.

Seconds vs milliseconds

POSIX, most Unix tools, and many backend languages use seconds. JavaScript's Date.now(), Java's System.currentTimeMillis(), and most modern web APIs use milliseconds. This converter auto-detects which you've pasted (numbers around 10 digits = seconds, around 13 digits = ms) but you can override the unit if needed.

How developers use this tool

  • Reading iat and exp claims from a JWT to check expiry
  • Debugging server logs that record events with epoch timestamps
  • Verifying that a scheduled cron entry will fire when expected
  • Translating between user-facing dates and database timestamps

Supported formats

The date input accepts ISO 8601 (2024-01-15T10:30:00Z), RFC 2822 (Mon, 15 Jan 2024 10:30:00 GMT), and most other formats the browser's Date constructor understands. The output is shown simultaneously as a Unix timestamp (seconds and milliseconds), an ISO string, a localized human-readable form, and a relative time like "3 hours ago".
