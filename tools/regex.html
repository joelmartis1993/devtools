About the regex tester

Regular expressions are one of the most powerful — and least readable — tools in a developer's belt. A live regex tester shortens the feedback loop dramatically: you type a pattern and immediately see what it matches, what it captures, and where it fails. This tool uses the JavaScript regex engine, the same one your application code uses in browsers and Node.js.

Flags at a glance

  • g — find all matches (without it, only the first)
  • i — case-insensitive matching
  • m — ^ and $ match line starts/ends instead of the whole string
  • s — . matches newline characters too
  • u — full Unicode mode (required for \p{…} properties)

Practical examples

Extracting all email addresses from a text dump: [\w.+-]+@[\w-]+\.[\w.-]+ with the g flag. Validating a hex color: ^#(?:[0-9a-fA-F]{3}){1,2}$. Splitting CSV rows that may contain quoted commas: "([^"]*)"|([^,]+).

How matches are displayed

The right-hand panel highlights every match in your test string and lists each match below with its index in the input. Capture groups are not highlighted separately, but they appear in the match list so you can verify your groupings. If your pattern is malformed, you'll see the exact error from the JavaScript engine — including the position of the offending character.

Privacy

All evaluation happens locally in your browser. Patterns and test strings are never transmitted, which makes this tool safe for testing against real production logs or user data.
