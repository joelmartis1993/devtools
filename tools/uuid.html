About UUIDs

A UUID (Universally Unique Identifier), also called a GUID, is a 128-bit identifier that's statistically guaranteed to be unique across space and time without coordination. It's the standard way to assign primary keys when you can't (or don't want to) rely on a centralized counter.

Why version 4?

Version 4 UUIDs are derived from cryptographically secure random numbers, with two fixed bits identifying the variant and four fixed bits identifying the version. They're the most common variant for general application use because they leak no information about the host or the time of generation, unlike v1 (MAC + timestamp) or v3/v5 (hashed).

Common uses

  • Primary keys for distributed databases and event logs
  • Idempotency tokens for API requests
  • Session and correlation identifiers
  • File names that must not collide across uploads
  • OAuth state parameters and CSRF tokens

How this generator works

It uses the browser's native crypto.randomUUID() when available (modern Chrome, Firefox, Safari) and falls back to crypto.getRandomValues() with the correct version and variant bits. Either way, the randomness comes from the operating system's CSPRNG — never Math.random(). All IDs are generated locally; the server never sees them.

Format options

The standard string form is xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx (lowercase hex with dashes). Toggle the options above for uppercase, no dashes (32-character hex), or curly braces ({…}) — common in Microsoft and SQL Server contexts.
